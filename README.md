# HR Synergy

## Human Resource Management System

HR Synergy is a Human Resource Management System developed during my Java with Spring Boot Internship at Softpro India Computer Technologies Pvt. Ltd.

The application streamlines HR operations by managing employees, recruitment, candidates, and related workflows through a secure and user-friendly interface.


## Features

- Employee Management
- Candidate Management
- Recruitment Management
- CRUD Operations
- RESTful APIs
- Authentication & Authorization
- Database Integration
- Responsive User Interface
